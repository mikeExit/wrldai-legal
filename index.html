EXIT Social Publisher — Privacy Policy

Last updated: 25 July 2026

This policy covers the EXIT Social Publisher, a private internal tool used by its operator to publish content to their own social media accounts on Instagram and LinkedIn. EXIT is a smoking-cessation mobile app. This tool publishes marketing content about EXIT to EXIT's own social accounts. It is not a public service, it is not distributed to anyone, and it has no end users other than the account owner.

This policy does not cover the EXIT mobile app itself. The EXIT mobile app is a separate product with its own users and its own privacy policy. Nothing in this document describes the app, and this tool has no access to any app user's data.

What the tool accesses

Instagram, through the official Instagram API, and only for the connected account:

  • Basic account information — account id, username and account type (permission: instagram_business_basic). Used to confirm the connection is valid before publishing.
  • Content publishing — uploads and publishes Reels, feed images and Stories that the operator has created and explicitly approved (permission: instagram_business_content_publish).
  • Metrics on its own posts — aggregate like and comment counts, timestamp and permalink, used to review the performance of content it published.

LinkedIn, through the official LinkedIn API, and only for the connected profile or Page:

  • Identity verification — the authenticated member's own identifier, read once via OpenID Connect (/v2/userinfo) purely to confirm the access token is still valid before publishing.
  • Content publishing — creates text posts that the operator has written and explicitly approved (permission: w_member_social for a personal profile, or w_organization_social when publishing as a Company Page).

Nothing publishes without explicit approval

Every publish is gated. The tool refuses to send anything to any platform unless a matching human approval has been recorded first; without one it writes a proposal for review and makes no network call at all. There is no automatic, scheduled or unattended posting.

Images are published to a public URL

The Instagram API can only publish a still image from a publicly reachable URL — it fetches the file itself rather than accepting an upload. Images intended for Instagram are therefore first uploaded to a public GitHub repository so that Instagram can retrieve them, which means any image published through this tool is publicly accessible at that URL. Only finished marketing images the operator has approved for publication are ever placed there. Videos (Reels) are uploaded directly to Instagram and are not hosted publicly by this tool.

What the tool stores

  • Access tokens and the account identifiers they belong to — the Instagram user id, and the LinkedIn author URN — held in a local environment file on the operator's own machine. Nothing is stored on a hosted server, shared database or third-party service.
  • A local record of what was published and when, kept on the same machine so the operator can review their own activity.
  • Nothing else. The tool does not collect, store or process personal data belonging to any other Instagram or LinkedIn user, follower or visitor.

What the tool never does

  • It does not read, collect or store other people's profiles, followers, connections, comments, direct messages or contact details.
  • It does not sell, share, rent or transfer any data to anyone.
  • It does not use any data for advertising, profiling or training.
  • It does not use any automation that acts on behalf of other users, and it does not access any account other than the operator's own.

Retention and deletion

Tokens live only in the operator's local environment file and are removed by deleting them from it. Access can be revoked at any time from the Instagram or LinkedIn account settings, which immediately and permanently ends this tool's ability to access or publish to that account. Because no data about any other person is collected, there is no third-party data to delete; any request concerning data held by this tool can be sent to the contact address below and will be actioned.

Children

This tool is an internal operator utility. It is not directed at children and collects no data from anyone, including children.

Changes

If what the tool accesses or stores changes, this page is updated and the date at the top changes with it.
